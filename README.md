# Sutang River Project

## Add this to your existing River Project website

### Easiest method
1. Upload `sutang-river.html` into your GitHub Pages repository.
2. Add a navigation link from your existing homepage:
   `href="sutang-river.html"`
3. If your homepage is already called `index.html`, keep it unchanged and use the new page as a separate project page.

### Alternative
If you want Sutang to appear directly inside the existing homepage, copy the `<main class="wrap">...</main>` content from `sutang-river.html` into your existing page and copy the `<style>...</style>` block into the existing `<head>`.

## Important source policy
The page intentionally distinguishes:
- Government/official records
- Institutional research
- Academic research
- Journalism/context
- Unverified research tasks

Do not replace the “data gap” sections with guesses. Add old maps/photos only after the original source, date and location have been verified.

## Verified baseline used in this version
- Government river dataset: Sutang, BWDB Id NE-82
- Government dataset length: 82 km
- Width: 21–62 m, average 36 m
- Transboundary, non-tidal, seasonal
- Government route: India → Chunarughat → Habiganj Sadar → Lakhai → Meghna (Upper)
- BWDB water-quality station: SW280, Sutang Railway Bridge
- NRCC 2024 pollution-control monitoring notice
- Official 2026 e-GP tender for 6.5 km dredging/re-excavation

This is a research website, so source links should be kept visible and updated when new primary evidence is found.
